# Daily Digest Log

Appended once per weekday firing of the pilot routine (`RemoteTrigger`
`trig_01SAdNQQrkWcUvqr9ff4Wfc6`), immediately after Step 3 of its normal work. This
file is the human-readable rollup of what changed that day and why — `outcome-log.md`
and `retrospective-log.md` stay the raw data; this file is the narrative on top of it.
A condensed version of each entry is also sent as a mobile push notification the same
day (via `PushNotification`) — this file is the full version for anyone who wants more
than the notification shows.

**Format per entry (see the spec in `earnings-report/CLAUDE.md`'s "Daily Digest"
section for the full rules):**

```
## Daily Digest — YYYY-MM-DD

**Tickers touched today:** N ([list])

### TICKER (Track: Full Deep-Dive | Monitor-Only)
- **What changed:** [the specific event from today's run]
- **Why (rubric/source):** [which factor-guide.md section fired, one-line evidence]
- **Swing outlook:** [what this means for entry timing — Confirmation Gate state,
  Drift Classification, or "still pre-print, no outlook yet"]

[repeat per ticker touched]

**No change today:** [tickers checked but nothing material — one line each, or
"none checked today" if nothing was in-window]

**Upside watch (pre-print, unchanged):** every still-pre-print name whose original
§1/§2 setup was skeptical (off highs) + cheap/reasonable valuation — i.e. still
carries a "real rally room on a clean beat" case per its Conditional Reaction Matrix
— gets listed here even when nothing changed today. Required every day any pre-print
name exists in either track; never omit this section just because nothing moved. This
exists specifically so a quiet day doesn't read as "nothing interesting" when a live
bullish setup is simply still waiting on its print — a compressed "no material change"
note alone is not sufficient for these names.
```
